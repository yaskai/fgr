# Fish Game 

## Run Instructions

Step one for all platforms is cloning the repo
either: 

through git gui

OR 

running this commmand in your terminal
``` bash
git clone https://github.com/yaskai/fgr
```

### Unix (MacOS + Linux)

Navigate to root directory
``` bash
cd fgr
```

Then bin
``` bash
cd ./bin
```

Change permissisions of the executable
``` bash
chmod +x ./game
```

Run executable
``` bash
./game
```
